# Security reporting

For a suspected security issue in mpeek itself, use GitHub's private vulnerability
reporting option if it is available on this repository. Otherwise, contact the
maintainer [AndriGitDev](https://github.com/AndriGitDev) through GitHub with a
request for a private reporting channel, without posting sensitive details.

Do not include credentials, real target inventories, scan reports, or packet
captures in a public issue. A vulnerability found in another product should be
reported to that product's maintainer through its disclosure process.

Only the current release candidate is maintained at present. mpeek inventories
exposure; it neither verifies exploitation nor replaces vendor patch guidance.
